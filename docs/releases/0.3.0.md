# A/L Results Collector 0.3.0

Qt Quick is now the default interface launched by `checker.py` and `run.cmd`.
The Tkinter interface, its dependencies and obsolete comparison source have been
retired. Existing browser, parser, Excel and checkpoint modules are retained.

The app, window, installer and header use the new purple graduation-cap icon.
Windows icon resources include 16, 24, 32, 48, 64, 128 and 256 pixel sizes.

## Saved progress

The pre-migration source is preserved in commit `136e7ae`, branch
`codex/backup-before-qt-main-20261113`, and tag `backup/pre-qt-main-2026-11-13`.
The retired UI's application-data directory is left unchanged. The current Qt app
continues using its existing directory so tested Qt checkpoints remain available.
Consistent local SQLite backups were made outside the repository before migration.
No student data or local archives are included in the release source or bundle.

The installer retains the original product identity for upgrades, replaces only
the installed runtime payload, and does not delete application-data directories.

## Workbook format

The first worksheet requires a first-row header spelled exactly `NIC` and one
student NIC per row underneath. This is the only required column. Names, classes
and other columns are optional and retained. Store NICs as Excel text to preserve
leading zeros. Input files are never modified.

## Verification

- All 60 source tests pass, including launcher failure/report handling.
- The relocated Windows bundle starts without a Python/source search path and uses
  Direct3D 11. The packaged Selenium Manager executable runs successfully.
- The packaged offline test verifies all 1,500 rows, stop/resume, partial and final
  export, exact simulated outcomes and unchanged input.
- Installer tests use a separate product identity. Installation removes stale Tk
  runtime files; uninstall removes installed payload while preserving user-owned
  files and original checkpoint/preferences hashes.

The one-folder application is built with PyInstaller 6.22.3, PySide6 Essentials
6.12.0 and Python 3.15. The per-user installer uses Inno Setup 6.7.4. Build-time PATH
is restricted to prevent unrelated development-tool DLLs entering the bundle.
Third-party notices and licence texts are included.

These are unsigned builds verified on the development machine. A separate Windows
computer without Python still needs an installation and small real collection test
before public release. Mock tests do not measure Chrome, network or CAPTCHA cost.
