# A/L Results Collector 0.3.1

- Include Selenium's dynamically imported WebDriver modules in the Windows bundle.
  This fixes missing `selenium.webdriver.chrome.options` when starting collection.
- Closing Chrome now stops collection cleanly. Completed rows remain saved and the
  interrupted student stays pending for resume. A Stop request racing with a
  browser error is handled as a stop, not a fatal collection failure.
- The UI explains that Chrome was closed and how to reopen it by starting again.
  Genuine WebDriver failures remain errors, without dumping native stack traces.
- Release verification now launches real headless Chrome, enters fictional text
  into a local page, reads/parses its result, and verifies closed-session detection.
  This complements the existing mock-data and Excel/checkpoint tests. No student
  lookup or CAPTCHA is performed; Selenium Manager may download a driver if needed.

Existing checkpoint and preference directories are unchanged. Install 0.3.1 over
the previous version, or replace the entire portable folder. Restart source
instances after updating. The purple graduation-cap icon is retained.

## Verification

66 source tests pass, including the pending-row preservation, Stop/error race,
concise error messages, UI resume, and real local Chrome checks. The rebuilt,
relocated EXE and installed 0.3.1 application both passed real Chrome startup,
local result parsing, closed-session detection, and the complete 1,500-row mock
workflow. Installer/uninstaller tests preserved existing checkpoint/preference
hashes. No examination-site student lookup was performed.
